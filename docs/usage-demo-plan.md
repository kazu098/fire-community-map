# FIREコミュニティマップ 使い方キャプチャー/動画化メモ

## 結論

PlaywrightでFIREコミュニティマップを操作しながら画面キャプチャーすることは可能です。
ただし、音声ナレーション付き動画まで一度に作るより、先にサイト内の「使い方」タブを説明台本として整備し、画面キャプチャーまたは無音動画を作ってから音声を重ねる方が安全です。

## 推奨する段階

1. ローカルで `index.html` を開き、「使い方」タブの静的ドキュメントを確認する。
2. 左サイドバーの目次から、各セクションへ移動できることを確認する。
3. 各操作方法に対応するスクリーンショットをPlaywrightで保存する。
4. 同じ順序でPlaywright操作を録画する。
5. 「使い方」タブの文章を台本にして、別録りまたはTTSで音声を追加する。

## 静的ドキュメントの構成

- レイアウトは Just the Docs 系のガイドに近い構成にする。
- 左側にガイド名、検索欄、目次を置く。
- 中央に本文を置き、見出しごとに説明、操作手順、スクリーンショット、注意点を並べる。
- 全体像: FIREコミュニティマップにどのような情報があるか。
- メンバー登録申請: メンバータブの「登録はこちらから」からGoogleフォームを開き、ニックネームを入力する流れ。
- メンバー表示: 申請後、担当者の手動反映でメンバー一覧に表示されること。
- 情報修正・外部公開設定: タグ追加、タグ内の「✕」削除、リンク追加、外部公開ON/OFF、外部向け自己紹介文。
- 地図タブ: メンバー/旅行グルメのレイヤー切り替え、ニックネーム検索、ピンのポップアップ。
- イベントタブ: 開催予定/開催済み、日程調整中、Discordリンク。
- メンバー詳細: 紐づいた読んだ本・旅行投稿を一覧から外す操作。
- 暮らしの知恵タブ: カテゴリ切り替え、検索。
- 動画化メモ: Playwright録画と音声追加の流れ。

## キャプチャーで見せる内容

- メンバー登録申請: Googleフォームで申請ニックネームを送るだけでよいこと。
- 登録反映: 担当者が確認して反映するためラグがあること、同じフォームを何度も送る必要はないこと。
- メンバータブ: 検索、メンバー詳細、タグの追加、タグ内の「✕」削除、リンク追加。
- 外部公開設定: 公開してよい項目だけONにすること、外部向け自己紹介文を内部向け自己紹介と分けること。
- 地図タブ: メンバー/旅行グルメのレイヤー切り替え、ニックネーム検索。
- イベントタブ: 開催予定/開催済みの切り替え、日程調整中イベントの見え方。
- 暮らしの知恵タブ: 投稿検索、カテゴリ切り替え。

## カズさん操作の扱い

動画では「カズさんが管理者/開発者として画面を操作して説明している」想定にします。
実データをそのまま見せる場合は、個人情報や内部向けメモが映り込まないよう、撮影前に表示範囲を確認してください。

## Playwright実装時の注意

- このリポジトリには現時点でPlaywright依存は入っていません。
- 導入する場合は `@playwright/test` をdev dependencyとして追加し、`page.video()` またはtrace/screenshotを使います。
- 地図タイル、Supabase、Leaflet CDNを読むため、ローカル確認でもネットワーク接続が必要です。
- 音声はPlaywright単体では生成しません。別録り、TTS、または動画編集工程で追加します。
- 操作中にタグ追加や削除を実行するとSupabaseに実データ変更が入るため、動画用には編集ボタンを見せるだけにするか、テスト用メンバーを用意してください。
