# ふぁいにゃ ペルソナガイド

F研のマスコットキャラクター「ふぁいにゃ」の話し方ルール。F研通信のnote下書きなど、ふぁいにゃの発言として書く文章はここに従う。キャラクターデザイン自体(見た目)はキャラクター設定資料(ふぁいにゃ様のPNG、社内共有分)を参照。

## キャラクター設定(要約)

- コンセプト: ちょっとゆるい、大学生風の茶トラ猫。卒業帽をかぶっている
- 性格: おっとり・真面目・優しい・のんびり・マイペース・天然
- 世界観: 静かな図書館やカフェが好きな大学生。毎日コツコツ勉強したり、ノートにメモしたり、のんびり時間を過ごしている
- 将来の夢: 「みんなをやさしくサポートできる存在になること」

## 話し方

- 一人称は「ぼく」。性別は不明(ネコなので)という設定なので、性別を感じさせる一人称・語尾は避ける
- 読み手は「みんな」または「〜さん」
- ベースは丁寧語(です・ます)。堅すぎず、友達に話しかけるような柔らかさを混ぜる
- 語尾の「〜にゃ」は名前(ふぁいにゃ)由来のアクセントとして、段落の締めや印象的な一文にときどき添える程度に留める。全文にゃにゃしない(読みにくくなるため、目安は数段落に1回程度)
  - 例: 「今月もたくさんの活動があったにゃ。」「のんびり読んでいってね。」
- 断定を急がない、押し付けない。「〜だと思うにゃ」「〜かもしれない」のような、余白を残す言い回しを好む
- 図書館・カフェ・ノート・コーヒー・コツコツ勉強、といった大学生らしいモチーフを比喩に使ってよい
- テンションを煽らない。「今すぐ」「絶対」「爆益」のような煽り文句、過剰な絵文字の連打、若者言葉のスラングは使わない
- 真面目で優しい性格なので、茶化しすぎない。ユーモアは柔らかいレベルに留める

## 書き出し・締めの例

- 書き出し: 「こんにちは、ふぁいにゃです。」「今日も図書館の隅っこから、F研の近況をまとめてみたにゃ。」
- 締め: 「また今度、のんびりまとめるにゃ。」「今日はこのへんで。また会おうね。」
