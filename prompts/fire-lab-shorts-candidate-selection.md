# Fire研究所 切り抜き候補選定プロンプト

以下のYouTube文字起こしから、YouTube Shorts向けの切り抜き候補を3〜5本選んでください。

## 入力

- 動画タイトル
- 動画URL
- `transcript.tsv`
  - 形式: `開始秒<TAB>テキスト`
  - YouTube自動字幕なので誤字があります

## 選定基準

- 45〜60秒で意味が通る
- 冒頭3秒にフックがある
- FIRE、資産形成、早期退職、会社員の悩みとして視聴者が自分ごと化しやすい
- 発話途中で切らず、句読点または意味の切れ目で区切る
- 可能なら1本の連続区間を優先し、飛ばす場合も最大3セグメントまで
- 元発話から離れた要約字幕にしすぎない
- 自動字幕の誤変換は自然な日本語に補正する。ただし話者の主張は変えない
- 切り抜き後の全尺を`captions`で埋める。途中から字幕が消える候補は不可

## 出力

次のJSON形式だけで返してください。説明文は不要です。

```json
{
  "video_url": "https://youtu.be/VIDEO_ID",
  "video_id": "VIDEO_ID",
  "title": "動画タイトル",
  "clips": [
    {
      "slug": "short_pattern_01",
      "title": "切り抜きタイトル",
      "header": "FIRE経験者のリアル",
      "hook": "冒頭固定フック",
      "accent": "gold",
      "segments": [
        { "start": "12:29", "end": "13:11" }
      ],
      "captions": [
        {
          "start": "0:00",
          "end": "0:03",
          "text": "発話に沿った字幕",
          "accent": false
        }
      ],
      "notes": "誤変換補正や狙い"
    }
  ]
}
```

## 字幕ルール

- `captions[].start/end`は切り抜き後の動画内時刻です
- 最初の字幕は`0:00`から始める
- 最後の字幕は切り抜き動画の終了時刻まで届かせる
- 字幕同士の隙間は原則0秒。長くても0.35秒以内
- 字幕同士を大きく重ねない
- 1字幕は最大2行、1行15文字前後
- 強調したい字幕だけ`accent: true`
- 関西弁など話者のニュアンスは残してよい
- ただし誤変換は直す
- 例: `ふ切り` → `ふんぎり`
- 例: `1年伸ばし伸ばし国` → `1年伸ばし伸ばし症候群`

## 評価観点

各候補は、次のどれかの型に寄せてください。

- 後悔型: 「もっと早くやればよかった」
- 警告型: 「それ、実は危ない」
- 共感型: 「そこ見落としがち」
- 学び型: 「経験者だから言える判断軸」
- 論争型: 「コメントが分かれそうな問い」
